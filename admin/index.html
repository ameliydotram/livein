Admin sign-in

This page is public, but it can't change anything on its own. Saving needs a GitHub token with write access to ameliydotram/livein, and only you have that. The token is kept in this browser tab only (sessionStorage) and is never saved to the site.

How to create the token (free)

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it e.g. livein-admin, choose an expiry (e.g. 30 days).
  3. Repository access: Only select repositories → ameliydotram/livein.
  4. Permissions → Repository permissions → Contents: Read and write (Metadata: Read-only is added automatically). Nothing else.
  5. Generate, copy the token and paste it above. Revoke it any time from the same page.

Add entry

Saving commits data.json to the repo. GitHub Pages rebuilds, so changes go live in about a minute. Hotel entries are stored for future use (the Hotel tab is currently hidden in the app).

Delete?

This removes the entry and publishes the change.
